# Do Now Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One-tap "Do now" buttons for Boi, Shanti and Shokti in the menu bar panel and on the Dashboard, and every finished buddy session shows as an activity.

**Architecture:** A new `Engine.doNow(_:)` starts a session only when none runs. `finishSession` writes 1 finished `.buddy` activity when the live tracker did not own the session (tracker off, or the session started outside tracker hours). One shared `DoNowButton` view serves both screens.

**Tech Stack:** Swift 5.9, SwiftUI, Swift Testing, ViewInspector, `EngineHarness`.

**Spec:** `docs/superpowers/specs/2026-11-20-do-now-design.md`

## Global Constraints

- Work in worktree `../Sathi-do-now` on branch `feat/do-now` from `main`. Copy the spec and this plan into it.
- No code comments. Max 200 lines per file. No magic numbers (`UIMetrics`, `Timing`, `Limits`).
- SathiCore never imports SwiftUI. Engine reads time only from `clock.now`.
- Copy: Boi "Read now", Shanti "Breathe", Shokti "Move". Fota keeps "+1 glass" and gets no Do now button.
- No macOS calendar event for buddy activities. No saved data shape change.
- Tests first. `./scripts/test.sh` and `./scripts/lint.sh` pass after each task.

## Review Focus

1. A double tap or a tap while a session runs must not restart the timer. Expect: nothing happens. Test in Task 1 (`doNowDoesNothingWhileASessionRuns`).
2. Tracker on and session inside hours: exactly 1 activity, not 2. Test in Task 1.
3. Tracker on, but the session started before tracker hours: 1 finished activity. Test in Task 1.
4. A session that runs past midnight: the activity ends at midnight, like the live tracker. Test in Task 1.
5. Buddy turned off in Settings: no button. Test in Task 2.
